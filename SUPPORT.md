## Support

### Getting Help

We use GitHub for tracking bugs, feature requests, and general support. Please submit a GitHub issue for:

- Bug reports
- Feature requests
- Documentation issues
- General questions and support

### Issue Reporting

When reporting issues, please include:

1. **Clear title** describing the problem
2. **Detailed description** of the issue
3. **Steps to reproduce** the problem
4. **Expected vs actual behavior**
5. **Environment details**:
   - Python version
   - Operating system
   - SAS CI360 version (if applicable)
   - Relevant configuration

### Security Issues

For security-related issues, please do not open a public GitHub issue. See [SECURITY.md](SECURITY.md) for how to report a vulnerability.
